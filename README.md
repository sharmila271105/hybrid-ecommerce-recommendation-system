# Hybrid E-Commerce Recommendation System

An end-to-end e-commerce recommendation system built using the H&M Personalized Fashion Recommendations dataset.

## Recommendation Approaches

- Popularity-Based Recommendation
- Content-Based Filtering
- Collaborative Filtering using ALS
- Hybrid Recommendation

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- ALS
- FastAPI
- Streamlit
- Docker

## Project Pipeline

Data Acquisition
→ EDA
→ Preprocessing
→ Content-Based Filtering
→ Collaborative Filtering
→ Hybrid Recommendation
→ Evaluation
→ FastAPI
→ Streamlit
→ Deployment
